# Example Data Fixture (`data/example/`)

This directory houses the synthetic public data fixture for `kreier/maintenance`.

## Purpose
1. **Public Demonstration**: Powering the static demo running on GitHub Pages without requiring authentication or a live backend.
2. **CI Test Fixture**: Used in automated CI tests to validate schemas, age computation algorithms, search indexing, and translation checkers.
3. **Template for Real Installations**: Serving as an explicit reference for how a real facility's R2 `data/` directory will be structured.

> [!IMPORTANT]
> All information in this directory is synthetic and safe to be publicly readable. Real facility data must **never** be placed here.
